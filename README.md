# JavaScript: condicionales

## Instrucciones

1. Abre esta carpeta con Visual Studio Code.
2. Abre el HTML correspondiente (index1.html a index11.html) con **Live Server**.
3. Abre la consola del navegador: **F12 → Consola**.
4. Lee el enunciado y modifica el JavaScript dentro de la etiqueta <script> del HTML.
5. Guarda y comprueba los mensajes de la consola.
6. Despliega **Resultado esperado** después de intentarlo para comparar tu respuesta.

Cada HTML contiene su propio JavaScript. No necesitas instalar dependencias.
