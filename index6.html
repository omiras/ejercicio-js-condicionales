Ejercicio 6 · Combinar condiciones con &&

Practica paso a paso con condiciones y variables.

Antes de empezar

El operador && significa Y: para que la condición completa sea verdadera, deben ser verdaderas las dos condiciones.

if (8 > 4 && 2 > 6) {
  console.log("Se cumplen las dos");
}

La primera comparación es verdadera, pero la segunda es falsa. Por eso no aparece el mensaje.

Con &&, no basta con que se cumpla una de las dos condiciones.
