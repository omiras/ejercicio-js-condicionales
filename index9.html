Ejercicio 9 · Negar una condición

Practica paso a paso con condiciones y variables.

Antes de empezar

Las variables booleanas pueden guardar true (verdadero) o false (falso), sin comillas. El operador ! invierte ese valor.

let tengoEntrada = true;
let estaCancelado = false;

if (tengoEntrada && !estaCancelado) {
  console.log("Puedo asistir");
}

La condición se lee «tengo entrada y no está cancelado». Como !false es true, las dos partes se cumplen.

!true da false y !false da true. Asigna valores booleanos a las dos variables del ejercicio antes de comprobar la condición.
