Ejercicio 5 · Escribir un if...else

Practica paso a paso con condiciones y variables.

Antes de empezar

Para escribir un if...else, coloca la condición entre paréntesis y las instrucciones de cada caso entre llaves.

let puntos = 10;

if (puntos >= 8) {
  console.log("Objetivo conseguido");
} else {
  console.log("Sigue intentándolo");
}

El operador >= significa mayor o igual que. El valor del límite pertenece al primer caso.

Comprueba tu solución con un valor menor que el límite, otro igual y otro mayor. Así verificarás los dos caminos y el caso de igualdad.
