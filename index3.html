Ejercicio 3 · Entender un if

Objetivo: decidir qué instrucciones se ejecutan según el valor de una variable.

Antes de empezar

Un if comprueba una condición. Si es verdadera, ejecuta las instrucciones entre llaves. Si es falsa, las salta y continúa con el resto del código.

let temperatura = 28;

if (temperatura > 25) {
  console.log("Hace calor");
}

console.log("Fin de la comprobación");

Como 28 > 25 es verdadero, aparecen los dos mensajes. Si la temperatura fuera 20, solo aparecería «Fin de la comprobación».

El símbolo > significa mayor que: si los dos valores son iguales, la condición es falsa.

En este ejercicio hay tres if independientes. Se comprueban uno tras otro: que se ejecute el primero no impide que también se ejecuten los siguientes.
