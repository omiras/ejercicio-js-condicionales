Ejercicio 1 · Elegir entre dos caminos

Practica paso a paso con condiciones y variables.

Antes de empezar

Un if...else permite elegir entre dos caminos. Si la condición es verdadera, se ejecuta el bloque del if. Si es falsa, se ejecuta el del else.

if (8 > 10) {
  console.log("Se cumple");
} else {
  console.log("No se cumple");
}

Como 8 > 10 es falso, aparece «No se cumple».

Solo se ejecuta uno de los dos bloques. Lee primero la condición y decide qué camino seguirá el programa.
