Ejercicio 5 - Condicionales JavaScript

Abre este archivo con Live Server y abre la consola del navegador (F12 → Consola).

  1. Escribe un if...else: si numero vale 5 o más, muestra «El número es mayor o igual que 5». En caso contrario, muestra «El número es menor de 5».
  2. Prueba ambas posibilidades cambiando numero.

🎬 Vídeo de apoyo

Edita el código dentro de la etiqueta <script>, guarda y consulta la consola.

Resultado esperado (pulsa para verlo) 
Con numero = 5: El número es mayor o igual que 5
