Ejercicio 7 · Comprobar dos datos

Practica paso a paso con condiciones y variables.

Antes de empezar

El operador == compara dos valores. En este ejercicio comparamos textos: deben coincidir sus caracteres, incluidas las mayúsculas.

let color = "verde";
let talla = "M";

if (color == "verde" && talla == "L") {
  console.log("Producto encontrado");
}

El color coincide, pero la talla no. El mensaje solo aparece cuando coinciden los dos datos.

= asigna un valor; == lo compara. Modifica las variables y conserva la condición del ejercicio.
