Ejercicio 4 · Cumplir solo una condición

Practica paso a paso con condiciones y variables.

Antes de empezar

El operador <= significa menor o igual que. La condición se cumple tanto con un valor menor como con uno exactamente igual al límite.

let edad = 12;

if (edad <= 16) {
  console.log("Descuento joven");
}

if (edad <= 10) {
  console.log("Descuento infantil");
}

Con 12 se cumple la primera condición, pero no la segunda. Como son dos if independientes, se comprueban ambos.

Para obtener un solo mensaje, busca un valor que haga verdadera la primera condición y falsa la segunda.
