Ejercicio 10 · Aplicar condicionales a una tarjeta

Practica paso a paso con condiciones y variables.

Antes de empezar

Una variable puede recibir un nuevo valor con =. Un if...else permite decidir qué valor asignar según una condición.

let stock = 8;
let estado = "";

if (stock > 5) {
  estado = "Disponible";
} else {
  estado = "Últimas unidades";
}

Las instrucciones se ejecutan de arriba abajo. Primero cambia el dato, después evalúa la condición y, al final, utiliza el resultado.

Para acortar un texto, substring(0, 12) obtiene sus primeros 12 caracteres. Puedes añadir puntos suspensivos con +:

let aviso = "Consulta todas las novedades";
aviso = aviso.substring(0, 12) + "...";

El código final ya actualiza la tarjeta usando tus variables. Trabaja en la zona indicada del último <script>; no necesitas modificar las instrucciones que actualizan el HTML.

Tu turno

Abre este archivo con Live Server y abre la consola del navegador (F12 → Consola).

  1. Asigna 59 a precio y comprueba el cambio en la tarjeta.
  2. Escribe un if...else: si precio es mayor que 50, asigna "text-red-500" a claseCSS; en caso contrario, "text-blue-500".
  3. Acorta whyUs usando substring y añade puntos suspensivos. Debe quedar parecido a «Tutorials by industry experts Peer & expert code review ...».
  4. Cambia la asignación del primer apartado a 10. Observa el color y explica por qué cambia.
  5. Antes del recorte, asigna a whyUs: «Los estudiantes de programación web eran tan buenos que hasta el HTML se renderizaba con una sonrisa.». Comprueba que también se acorta el nuevo texto.

Guarda los cambios y comprueba el resultado en la tarjeta. Su diseño utiliza recursos externos y requiere conexión a Internet.

Resultado esperado (pulsa para verlo)
  1. El precio pasa a 59.
  2. El precio aparece rojo si es mayor de 50; azul en caso contrario.
  3. Why Us se acorta usando substring y termina en puntos suspensivos.
  4. Al cambiar el precio a 10 antes del condicional, aparece azul.
  5. Al sustituir el texto original por el de los estudiantes, el recorte se aplica al nuevo texto.
