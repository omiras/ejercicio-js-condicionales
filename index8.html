Ejercicio 8 · La palabra secreta del día

Comprueba un intento usando el operador !=.

Antes de empezar

El operador != significa distinto de. Al comparar dos textos, la condición es verdadera si son diferentes.

También puedes comparar dos variables: se comparan los valores que contienen.

let color = "azul";
let colorEsperado = "rojo";

if (color != colorEsperado) {
  console.log("El color es diferente de rojo");
} else {
  console.log("El color es rojo");
}

Como «azul» es distinto de «rojo», se ejecuta el primer bloque. Si ambos textos fueran iguales, se ejecutaría el else.

Con != comprobamos si hay un error. Si la condición es falsa, los textos coinciden. Las mayúsculas y los espacios también cuentan al comparar.
