Ejercicio 2 · Comparar una variable

Practica paso a paso con condiciones y variables.

Antes de empezar

Una condición puede comparar el valor de una variable. Al llegar al if, JavaScript utiliza el valor que tiene la variable en ese momento.

let edad = 16;

if (edad < 12) {
  console.log("Entrada infantil");
} else {
  console.log("Entrada general");
}

Se compara 16 < 12. Como es falso, se ejecuta el else.

El símbolo < significa menor que. Si los dos valores son iguales, la condición también es falsa.
