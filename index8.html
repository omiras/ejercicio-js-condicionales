Ejercicio 8 · Comprobar una diferencia

Practica paso a paso con condiciones y variables.

Antes de empezar

El operador != significa distinto de. Al comparar textos, la condición es verdadera cuando los textos son diferentes.

let color = "azul";

if (color != "rojo") {
  console.log("El color no es rojo");
}

Como «azul» es distinto de «rojo», aparece el mensaje. Si la variable valiera «rojo», no aparecería.

En este ejercicio se usa != para comparar dos valores. No lo confundas con !, que niega una condición.
